# GHAI agent orchestration playground

This project explores how capability gateways, agent runtimes, trusted skills,
tools, and execution environments can work together in clear, bounded recipes.

The intended scope includes generation, media, decision workflows, retrieval,
and development tasks. Each recipe should state its protocol, permissions,
limits, completion evidence, and outputs.

Runtime connection details and model selections belong in repository secrets.
This public snapshot contains no concrete deployment endpoints or model presets.

Implementation examples are being prepared with privacy-safe configuration,
deterministic tests, and human-readable results. No live workflow is included in
this snapshot.
